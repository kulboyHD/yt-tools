📖 Hướng dẫn lấy API Key
  1. Truy cập Google AI Studio → API Keys
  2. Đăng nhập bằng tài khoản Google
  3. Click "Create API Key" → chọn project có billing (nếu dùng credits) → Copy key
  4. Dán key vào ô trên. Key được lưu tự động.
⚠️ Quan trọng: Để dùng credits, khi "Create API Key" phải chọn đúng project đã bật billing. Nếu chọn project chưa có billing sẽ dùng free tier.
