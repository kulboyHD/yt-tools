📖 Hướng dẫn lấy API Key (5 phút)
  1. Truy cập Google Cloud Console và đăng nhập
  2. Click "Select a project" ở góc trên → "New Project" → đặt tên bất kỳ → Create
  3. Ở thanh tìm kiếm trên cùng, gõ "YouTube Data API v3" → click vào kết quả → Enable
  4. Sau khi bật xong, click "Create Credentials" (hoặc vào menu APIs & Services → Credentials)
  5. Chọn "API Key" → Key sẽ hiện ra → Copy và dán vào ô trên
💡 Mỗi ngày bạn được 10,000 đơn vị API miễn phí (đủ tải ~500+ video). Key được lưu tự động trong trình duyệt.
ℹ️ Chế độ miễn phí sử dụng server Invidious. Có thể chậm hơn hoặc không khả dụng tùy thời điểm.
👉 Khuyên dùng chế độ YouTube API để nhanh và ổn định hơn.
