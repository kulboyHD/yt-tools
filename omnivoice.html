💡 Giới thiệu

OmniVoice là một hệ thống AI tạo giọng nói (TTS) mã nguồn mở mạnh mẽ, có khả năng nhân bản và tổng hợp giọng nói cho hơn 600 ngôn ngữ khác nhau. Dự án này cho phép bạn tạo ra các đoạn âm thanh tự nhiên, chân thực từ văn bản với khả năng kiểm soát cảm xúc và phong cách độc đáo.

✨ Tính năng chính

🌍
600+ ngôn ngữ
Hỗ trợ số lượng ngôn ngữ khổng lồ, bao gồm cả tiếng Việt với độ chính xác và tự nhiên cao.
🎙️
Voice Cloning
Nhân bản giọng nói (Zero-shot) chỉ cần một đoạn âm thanh mẫu ngắn 3-10 giây.
🎨
Voice Design
Tạo giọng nói hoàn toàn mới dựa trên các mô tả về giới tính, độ tuổi, và phong cách.
⚡
Tốc độ siêu nhanh
Hiệu suất inference ấn tượng, có thể đạt tới 40x thời gian thực trên các GPU hiện đại.
🔧
Điều khiển chi tiết
Hỗ trợ các thẻ điều khiển cảm xúc như cười, thở dài, thì thầm hoặc thay đổi nhịp điệu.
🧠
Kiến trúc Diffusion
Sử dụng mô hình ngôn ngữ dựa trên Diffusion tiên tiến để đạt chất lượng âm thanh vượt trội.

⚙️ Hướng dẫn cài đặt

Thực hiện các bước sau để cài đặt OmniVoice trên máy của bạn:

Bước 1: Cài đặt Python 3.10+ (nếu chưa có) và tạo môi trường ảo
python -m venv venv
# Windows: venv\Scripts\activate
# Linux/Mac: source venv/bin/activate
Bước 2: Cài đặt PyTorch phù hợp với hệ thống của bạn
# Dành cho GPU NVIDIA (Khuyến nghị)
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121

# Dành cho CPU / Apple Silicon (M1/M2/M3)
pip install torch torchvision torchaudio
Bước 3: Cài đặt OmniVoice
pip install omnivoice

🚀 Cách sử dụng

Khởi chạy giao diện Web UI (Gradio) để sử dụng một cách trực quan:

omnivoice-demo --ip 0.0.0.0 --port 8001

Sau đó mở trình duyệt và truy cập vào http://localhost:8001.

Sử dụng OmniVoice trực tiếp trong mã Python:

import torchaudio
from omnivoice import OmniVoice

# Khởi tạo mô hình
model = OmniVoice()

# Văn bản cần tổng hợp
text = "Xin chào, đây là giọng nói được tạo ra bởi AI."

# Đường dẫn file âm thanh mẫu (3-10 giây)
prompt_audio = "mau_giong.wav" 

# Tạo âm thanh
audio, sample_rate = model.synthesize(
    text=text,
    prompt_audio=prompt_audio,
    language="vi"
)

# Lưu kết quả
torchaudio.save("ket_qua.wav", audio, sample_rate)

Chạy trực tiếp từ dòng lệnh:

omnivoice-infer \
  --text "Chào mừng bạn đến với OmniVoice" \
  --prompt_audio mau.wav \
  --output ket_qua.wav \
  --lang vi
